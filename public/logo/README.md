# Logo VGT

Coloca aquí el archivo final del logo manteniendo estos nombres (el código ya los consume):

- `logo-vgt.svg` — **logo principal** (monograma VGT + wordmark). Usado en Navbar y Footer.
  Actualmente hay un **placeholder**; reemplázalo por el SVG definitivo.
- `logo-vgt-mark.svg` — (opcional) solo el monograma "VGT" para favicon/usos compactos.
- `og-image.png` — (opcional) imagen Open Graph 1200×630 para compartir en redes.

> El SVG debe usar `currentColor` o variables para adaptarse a tema claro/oscuro,
> o entregarse en dos variantes (`logo-vgt-light.svg` / `logo-vgt-dark.svg`) si el navy
> no contrasta sobre fondo oscuro.
